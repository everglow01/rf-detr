**E0：100 轮 baseline 分析与 E1 对照方案**

评估日期：2026-11-11。训练已正常完成，正式权重保留。本报告依据原始训练日志，以及对最佳/最终 EMA 权重的完整 GPU 重评估；未启动 E1 正式训练。

**结论**

原版 Seg Small 已经较快收敛，整体分割最佳是第 **63** 轮，而不是第 100 轮。后期有轻度过拟合和性能饱和，没有出现训练崩溃。果梗明显弱于两类番茄，主要可见问题包含掩码端点、宽度偏差、局部分割不完整和漏检；现有证据不支持把主要瓶颈一概描述为“果梗断裂”。E1 值得作为单独消融，但不能预设 soft-clDice 必然改善 mask AP。

**训练条件与最佳轮次**

模型为 RF-DETR-Seg Small，384 分辨率，官方预训练初始化；双卡、每卡 batch 8、累积 1、有效 batch 16、BF16、seed 42。训练 100 轮，AdamW，lr=1e-4，encoder lr=1.5e-4，weight decay=1e-4，lr_drop=70，关闭早停。训练集 1395 张、验证集 199 张，不使用测试集。

训练源码提交为 `a459eeade6387927c599a50f287a319a19d7ae82`，176 个远端源码文件已与启动归档比对一致。训练作业 `20261111-172658-8eff` 正常退出，fit 耗时 4542.13 秒，即 **75.70 分钟**；第 2～100 轮的轮耗时中位数约 45.14 秒。

| 原始日志指标 | 第 63 轮 | 第 100 轮 |
| --- | ---: | ---: |
| 整体 EMA mask AP50:95 | **69.3041%** | 68.3131% |
| 验证总损失 | 5.5860 | 5.7754 |
| 训练总损失 | 3.5114 | 2.9709 |

最佳权重为 `/usr/local/rfdetr26/output/output1/baseline-seg-small-v1-seed42/training/checkpoint_best_ema.pth`。检查点内部 `epoch=62` 使用从 0 开始的编号，对应用户习惯的第 63 轮。第 62、54、64、61 轮的整体 mask AP 也接近峰值，因此不能将单次验证中的第 63 轮视为普适最佳训练长度。

原始日志 `val/ema_AP/stem` 是 **bbox AP**，不是果梗 mask AP。原训练没有逐轮记录单类 mask AP，因此这里确定的是“整体 mask AP 最佳轮次”，不能声称第 63 轮同时也是果梗单类 mask AP 的历史最优。

**是否过拟合**

前 10～20 轮已到约 68.7% 整体 mask AP，后续提升较小；第 61～70 轮均值为 69.0291%，第 81～100 轮降至 68.4897%。最终相较峰值下降 **0.9910 个百分点**。

验证总损失在第 22 轮最低，为 5.4638，最终上升至 5.7754；同时训练损失仍下降。结合验证 AP 的后期下降，可以判断存在轻度过拟合。第 71 轮学习率降低后，没有恢复验证性能，但不能据此认定学习率降低是退化的原因。

需要区分损失组成：第 21～40 轮与第 81～100 轮的验证 mask Dice loss 均值分别为 0.05719 和 0.05712，基本稳定；分类损失同期从 0.47308 上升至 0.51550。训练有增强、使用即时权重，而验证使用 EMA，不能仅凭两条总损失曲线的绝对差距判断过拟合，也不能说所有分割子任务均明显恶化。

重评估与训练时的双卡、batch 8 设置不同，存在小幅数值差异：整体 mask AP 比原日志分别高约 0.144 和 0.078 个百分点。保留两套结果及来源，不覆盖历史日志；最佳轮次以原日志为准，E1 的补充指标必须使用与本次相同的独立评估条件。

额外的工作阈值诊断使用 score ≥ 0.3、mask IoU ≥ 0.5、按置信度进行一对一匹配。这些指标与 COCO AP 的定义不同：

| 固定阈值诊断 | 第 63 轮 EMA | 最终 EMA |
| --- | ---: | ---: |
| 果梗预测数 / 匹配成功数 | 129 / 108 | 124 / 107 |
| 召回率 | 89.2562%（108/121） | 88.4298%（107/121） |
| 精确率 | 83.7209%（108/129） | 86.2903%（107/124） |
| 未匹配 GT / 未匹配预测 | 13 / 21 | 14 / 17 |
| 匹配成功实例平均 mask IoU | 0.77947 | 0.77326 |
| 匹配成功实例平均 hard clDice | 0.93328 | 0.93021 |
| 未匹配 GT 计 0 的平均 hard clDice | 0.83301 | 0.82258 |

最终权重的固定阈值精确率稍高，同时召回率和 AP 较低，不能只取其中一个指标宣称最终更好。条件 clDice 排除了漏检和 IoU 不达标的实例，因此需要同时报告覆盖率及“未匹配计 0”的版本。

此处 hard clDice 使用二值预测和 `skimage.morphology.skeletonize`，用于离线诊断；它不等同于训练中的可微 soft-clDice loss，不能将两者数值直接互换。

脚本的 `fragmented_matched_count` 字段仅统计“预测中面积 ≥ 8 像素的 8 邻域连通分量数超过 GT”的匹配实例，数值为 0 和 1。这个名称并不严谨：该判据会计入远处孤立斑块，又排除未匹配实例、小碎片等问题，**不能直接解释为断裂率**。本次已逐例确认唯一新增分量属于 Image 27 的孤立区域。后续报告按“额外连通分量”解释，不以此替代主干连续性评估。

果梗 AP50 高、AP75 显著低，结合预测图，表明精确轮廓、端点覆盖以及漏检都值得关注。soft-clDice 对中心线覆盖和部分不完整掩码有合理的作用方向，但已匹配实例的 clDice 较高，提升空间可能有限；它也不直接优化分类置信度或框定位。需要让 E1 的实测结果决定是否保留、调权重，或把后续重点转向分辨率/特征细节等独立实验。

**E1 对照规则**

E1 仍训练 100 轮，从相同官方预训练权重初始化。保留原数据、split、seed 42、双卡每卡 batch 8、累积 1、384 分辨率、全部学习率/增强/EMA/选模规则。新增配置仅为：

```yaml
mask_cldice_loss_coef: 0.1
mask_cldice_class_ids: [1]
mask_cldice_iterations: 10
```

只对 GT 果梗类别、最终 decoder 层的匹配实例增加损失。系数 0.1 是初步对照设置，不是已调优结果。此轮不叠加关键点头，不同时改变训练轮数或学习率，也不从 E0 最佳权重继续训练。

沿用整体验证 EMA mask AP50:95 选择 checkpoint，同时报告果梗 AP50:95、AP50、AP75、固定阈值召回/精确率、条件 clDice、未匹配计 0 的 clDice、两类番茄 AP，以及训练耗时和显存。新增损失会改变总 loss 的定义，**不能直接比较 E0 与 E1 的总 loss 大小来判断改善**；应看分项和任务指标。

重点问题是“中心线覆盖改善是否伴随果梗精确分割收益”，不是只要求 clDice 上升。若收益很小或指标互有涨跌，应增加相同协议的配对种子重复；单个 seed 和这一个验证集不足以证明稳定提升。没有测试集，本次结果不应称为独立测试集表现。
