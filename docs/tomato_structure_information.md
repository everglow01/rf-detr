# clDice是否提供超出mask IoU的信息：冻结诊断协议

用户授权：训练集、冻结权重、正式仓库/GitHub同步；不修改分类损失或匹配器，不启动训练。

主权重为已完成的三组10轮固定EMA：baseline、centerline_ce、centerline_local_ce。相同训练集上以seed2026111701 无放回随机抽128张含果梗图、32张不含果梗图，两个增强seed42/43；每类随机顺序前后两半作为discovery/confirmation。 图片集合独立，两次增强、同一图多个GT/查询以及三个模型均不是独立样本。使用原生训练增强、batch1、eval模式100查询、BF16； 它不是Group DETR十三组训练模式或历史DDP轨迹的重放。只调用原生matcher(group_detr=1)标记匹配，绝不改代价或监督。 不使用验证图像预测、验证标签或验证成绩来选样本、阈值或指标。

先算全部查询的IoU和GT中心线覆盖；完整结构诊断保留IoU>=.1或中心线覆盖>=.9的候选，以及原生匹配、最高分类分数、最高IoU候选。 该规则按几何广泛纳入外扩反例，不能据此估计所有query的无条件分布。骨架为skimage二值骨架；clDice为双向覆盖的调和平均， 与训练soft-clDice近似不同。GT为空不定义clDice；空预测质量为0。只在增强GT有效区域计算，排除padding。

主要比较：同GT、同增强、同权重，IoU均>=.2且位于IoU=.5同一侧，IoU差\<=.02、clDice差>=.05； 先选IoU差最小的一对，再以clDice差较大、query顺序解并列。每GT至多一对，不按分数或想要的结论选。 预定敏感性检查为IoU差\<=.005。汇报实际IoU差和可配对图片覆盖，不能把有配对的子集代表全部样本。

除中心线召回、骨架精度和clDice外，记录FP/GT、FN/GT、GT内部连接指标：对每个GT连通分量， 计算其骨架点在P交GT的最大连通分量中所占数，再除以总GT骨架长度；另记被多个预测分量覆盖的GT分量数。 这些是几何描述，仍和重叠指标相关，不是独立临床/采摘功能标签；不能通过clDice与自身分子的相关性证明新增价值。 主要看等IoU时外扩、连接差异以及分类分数的关系，discovery和confirmation分别报告，不拟合任何分类器。

重点集合：存在IoU>=.5候选但合格候选最高分\<.3；中心线覆盖>=.9且FP/GT>=.5； 另单独检查完整clDice>=.9且FP/GT>=.5的反例，不能把单侧中心线覆盖冒充完整clDice。 每权重/集合保存按预定图片顺序遇到的前三张不同图片，明确为条件案例；保留反例及图像/掩码证据。

成功执行标准：三模型输入/增强GT哈希一致、权重与参数前后不变、无参数梯度、无backward、无optimizer；保存原始候选与配对。 解释标准：结构信息和分类排序信息分开。哪怕存在额外几何信息，也不等于新监督会提高召回； 在IoU条件下用IoU>=.5作为唯一正确性标签属于循环判断，不作为增量证明。没有信息或覆盖不足时如实报告， 不自动实施分类协调项、不开始短训、不根据结果放宽配对阈值。对训练/推理性能的结论均留待独立受控实验。

配对结果另按双方IoU均>=.5与均\<.5分层，不把不合格候选的结构差异当作低分好掩码的增量证据。 服务器复用既有`output/output1/baseline-analysis-20261111/eval-deps`中的scikit-image，不安装或升级运行环境。
