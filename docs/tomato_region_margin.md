# 区域精度边界容差：冻结对照与短训门槛

假设：附加精度项对近边界像素的惩罚可能与细果梗补全竞争；只忽略GT外一小圈，检查能否保留明显越界抑制。 新增 mask_region_margin，默认0，单位为增强后原始GT网格像素，Chebyshev膨胀半径。 边界带B=dilate(GT,r)-GT；精度P=(sum(p*GT)+1)/(sum(p*GT)+sum(p\*far_background)+1)。 带内像素不受新增精度项处罚，也不会被计入正确前景；GT中心线、原生CE/Dice和评估GT不变。 只在region_centerline模式生效，默认关闭附加项，无预测骨架，r=0逐位复现旧公式。

冻结对照命令：scripts/diagnose_tomato_decoder_gradients.py --region-margin-probe。 固定总系数0.1、原生CE/Dice=5/5、类别1、K25、chunk4、三套既有最佳EMA和同一困难/对照队列。 仅比较a=0.25/0.1 × r=1/3四个候选；重放r=0全部旧档位。 主检查仍是当前漏分中心线和全部当前GT外假阳性的共享特征梯度；远于1/3像素的FP方向仅作解释，不能替换主检查。

## 预先固定的短训门槛

相对同a、r=0的配对参照，候选必须同时满足：

- 困难集合中，两项余弦均>0.05的GT组合数至少增加3个。
- 漏分中心线方向有利数、全部FP方向有利数均不减少；任一checkpoint对应数量均不能减少超过1个。
- 正常对照中上述两项受益数各不减少超过2个；已匹配低分好掩码的分类+mask+附加项合力保持升分。
- 所有旧梯度重放、有限值、默认关闭/原生权重不变检查通过；配对损失耗时比中位数不超过2，额外峰值allocated比中位数不超过1.5。

这些是小样本进入短训的工程门槛，不是显著性检验或真实效果保证。若多个候选通过，先比较明确同时受益数， 再比较中心线受益数，再优先小半径；保留全部结果。若无候选通过，不启动短训，不事后放宽门槛。

## 通过后才执行的短训及最终评估

从同一官方初始化开始，独立训练原版baseline与选中候选各10轮，保持原有seed42、双卡每卡batch8、 累积1、BF16和既有训练协议一致；只改变已验证的附加损失，E2关闭。不可与100轮baseline直接比较来判断短训收益。 固定第10轮EMA作主对照，不按候选结果事后选轮次；记录所有曲线和配置。 使用原GT、全部199张验证图（含无果梗图）评估果梗mask AP50:95与原生预测PR。 以本次短训baseline在score>=0.3时的精确率为共同下限，扫描两组原生阈值，在满足下限时取最高召回， 同时报告实际精确率、TP/FP/FN和阈值；离散计数未必能恰好等于同一精确率。并保留相同0.3阈值结果。 这是验证集探索性操作点对照，不是独立部署阈值验证，不增加测试集、不篡改GT。 先完成并报告冻结门槛，只有通过才启动10轮短训；不启动新一轮100轮训练。
