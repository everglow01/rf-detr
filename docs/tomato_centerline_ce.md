# GT中心线交叉熵：冻结标定与三组短训协议

实现：`centerline_ce` 只对GT骨架计算正类softplus(-logit)；`centerline_local_ce` 另外在GT外3像素 Chebyshev带内计算负类softplus(logit)。两项分别按各实例支持点数取均值，内部eta=1。 padding排除，空支持为有梯度连接的零；沿用最终匹配、Group DETR、DDP计数与chunk4；GT骨架K25。 无预测骨架，新增项默认系数0，只选果梗class1，不变更原生CE/Dice=5/5、分类、匹配或E2。 这是受clCE/Skeleton Recall启发的候选，不是完整论文复现或已证实的新方法。

冻结：三份既有最佳EMA，同一8困难+8对照GT，另从全部训练图按固定seed20261117随机顺序选16张 含非空果梗的增强训练图，不读取预测或验证成绩来筛选。504输入、batch8、三原生mask采样种子、共享decoder边界。 测量GT覆盖、中心线CE、中心线+邻近负类CE三种公式，探针系数统一0.1。

标定：只用baseline权重下16个随机训练GT的C组范数比中位数，把共用lambda缩放到原生mask的10%。 B/C两组lambda相同以隔离负类项；若任意已观察GT/种子的B或C范数比会超过1，则共同降低lambda到该上限。 此规则在读取结果前固定。报告中位数、极值与缩放，梯度夹角仅用于解释，不设全同向门槛，不用验证分数选系数。 诊断不包含上游或优化器更新，因此训练前增加完整模型的新项反向检查，证明梯度到达backbone/decoder/mask head。

短训：A原版，B仅中心线CE，C中心线+邻近负类CE，各10轮串行、同官方初始化、seed42、双卡每卡batch8、 累积1、BF16、原100轮学习率时间轴，第10轮停止，E2关闭。保留日志与权重，面板持续输出训练日志。 核对每rank初始化哈希、每轮首批增强数据、学习率与更新数一致。固定第10轮EMA为主比较，不事后挑有利轮次。

评估：原GT与全部199张验证图（含无果梗图），果梗mask AP50:95、固定0.3阈值计数， 以及以本次A组0.3阈值精确率为共同下限的最高召回，同时报告实际精确率、阈值、TP/FP/FN。 离散阈值不保证恰好相同精确率；阈值选择为验证集探索，没有新增测试集。十轮只用于筛查趋势，不宣称最终收益。 只有结构指标提高而任务指标退化，不启动百轮长训；后续长训和多种子需根据结果另定。
